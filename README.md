# Agentic Workspace

Lifecycle rules for the documents AI agents leave behind: a tool-free contract
with a conformance suite.

An agentic workspace accumulates plans, hand-offs, decisions, and notes.
[The contract](SPEC.md) says how to classify each of them and what eventually
happens to it, in twenty-six numbered clauses any implementation can be tested
against. It names no tool.
