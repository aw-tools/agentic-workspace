# Errata to superseded spec revisions

A superseded revision of `SPEC.md` is frozen at its `spec-r<N>` tag and is never
edited: a mistake in it is fixed in the current revision. This file holds the
corrections to superseded revisions, which aw.tools shows on each revision's
page.

Each superseded revision with corrections has one `## Revision N` heading,
followed by its corrections, one list item each. The current revision takes
none: it is corrected in `SPEC.md` itself.
